一句话

System 2 的价值在“覆盖”，不在“数据量”

System 2 在 System 1 快失败时接管，把 System 1 永远做不成的情况变成成功示范；把这些示范与 System 1 自己的成功回合一起模仿，得到的策略在新布局上更好（从零训练的 Diffusion Policy：4% → 15%，p = 0.002；原生数据加倍反而 1%），而且同样有 System 2 时更少需要它（教师步数 −17%，p = 0.004）。对已经预训练好的 pi0，直接改权重会在“学纠错”与“保正常行为”之间取舍，所以下一步改用参数隔离（System 1.5）。

从其他领域迁移来的四个机制

机制（来源领域）迁移到我们这里迁移依赖的条件证据
I1 推测解码：草稿模型提议、大模型验证（LLM 推理）System 1 = 草稿，System 2 = 验证器；接管与教师步数 = 拒绝率；模仿 System 2 = 把验证器蒸馏进草稿模型，应降低拒绝率System 2 的介入由廉价可验证的检测触发已成立：接管 −12%（p = 0.046）、教师步数 −17%（p = 0.004）
I2 在线难例挖掘（目标检测）System 2 只在 System 1 失败处接管，收割“难例”成功示范；System 1 自己的成功提供“易例”与一致性，二者互补System 2 能在 System 1 失败的配置上成功（已验证：33 个训练布局）已成立：等量原生 1/120，只用引导 4/120，二者结合 13–18/120；修正：收益在中等难度布局，最难布局未解决
I3 渐进网络 / 参数隔离（持续学习）System 1.5：pi0 冻结 + 只用 System 1 输入预测“System 2 会接管”的门控 + 用教师段训练的纠错器，部署时不需要 System 2门控精度足够；纠错器在接管处能成功间接：pi0 权重微调最好只到持平（−2 pp）；DP 能吸收 System 2 数据。待验证（X2）
I4 脚手架与淡出 / DAgger 迭代（教育、模仿学习）第二轮让 System 2 引导已经学会的学生本身，聚合后再训练，System 2 介入应越来越少学生能在引导模式下运行（已具备）进行中（X1）

第三段 · Report

方案报告（要点）

  • 形式化：训练布局与留出布局不相交；System 1 每 N 步输出动作块；System 2 = 失败检测器 + 执行器，调用有代价（接管次数、教师步数）。数据源：原生成功、引导成功（去掉接管前“快失败”窗口和失败的教师段）。目标：(a) 学到的 System 1 在留出布局上单独更好；(b) 仍有 System 2 时，调用更少且系统成功不降。
  • 核心新意：(1) System 2 的价值是覆盖而非数据量；(2) 把 System 2 调用代价当作蒸馏目标；(3) 对预训练 VLA 用参数隔离代替权重微调。
  • 与最近工作的区别：专家是自动 System 2，代价可量化；用等量原生对照和只用引导对照分离覆盖、互补与数据量；在留出配置上评测；把 System 2 蒸馏出部署回路而非常驻。
  • 方法：接管引导收集 → 数据清洗 → 学生学习（从零训练的 DP；或冻结 pi0 + 门控 + 纠错器）→ 迭代淡出。
  • 局限：System 2 目前是读仿真真值的特权脚本（Astra 在接入）；单任务、仿真；DP 绝对成功率不高且训练种子波动大；最难布局无人解决；pi0 权重微调尚未超过原版。
