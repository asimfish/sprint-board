结论汇总

到目前为止能说什么、不能说什么

  • 能说：两个策略上，增益都只属于搜索出的方向，剂量都有内部最优点。π0（14 个任务，同一批 280 个测试回合）：沿搜索方向 −4 / 0 / 2 / 4 / 6 / 8 / 12 倍为 7.9 / 29.6 / 55.4 / 68.6 / 61.1 / 42.1 / 7.5 %；同样大小的平移加在正交方向上为 30.7 %（与原生无差别）。4 倍下搜索方向比正交方向高 37.9 个百分点（区间 +26.8 到 +49.6），比相反方向高 60.7，比 12 倍高 61.1，三个登记问题都确认（PLA-CTRL-P0；π0.5 的对应结果见下面两条和剂量曲线图）。
  • 能说（筛查，不比较方法）：LIBERO 的扰动套件对 π0 两极分化：160 个任务单元里 73 个原生 16 次全败、48 个 16 次全成，有提升空间（成功 2–12 次）的只有 16 个；改指令措辞或物体属性几乎不影响 π0，换任务或交换物体位置则几乎全部失败（PLA-PRO-S）。第二个测试分布因此只有 16 个单元、13 个基础任务。
  • 能说（事后、描述性）：选一个统一剂量很便宜。把选剂量的试跑从每任务每强度 16 次减到 2 次（每任务 10 次，约为搜索预算的 5 %），选出的统一剂量在测试集上平均仍有 66.0 %（π0）和 72.4 %（π0.5），而用足 80 次是 68.6 % 和 74.4 %，不调（固定 2 倍）是 55.4 % 和 62.9 %。按任务各选一个剂量则不便宜：试跑少时反而不如统一剂量（账目与选剂量的代价）。
  • 能说：剂量有一个内部最优点，过大比不加还差（π0.5）：0 / 1 / 2 / 3 / 4 / 6 / 8 / 12 / 16 倍为 53.8 / 59.9 / 62.9 / 68.8 / 72.1 / 74.4 / 69.7 / 40.4 / 14.7 %；16 倍比 6 倍低 59.7 个百分点（区间 −76.0 到 −42.8）。在训练起点上用少量试跑选出的统一强度就是 6 倍，比原生高 20.6（PLA-DOSE-P05X）。
  • 能说：增益是搜索方向特有的（π0.5，同一批 680 个测试回合）：沿搜索方向 −6 / −3 / 0 / +3 / +6 倍为 26.6 / 38.5 / 53.8 / 68.8 / 74.4 %；同样大小的平移加在正交方向上为 53.7 / 51.0 %（与原生无差别）。6 倍下搜索方向比正交方向高 23.4 个百分点（区间 +10.0 到 +39.4），比相反方向高 47.8（PLA-CTRL-P05）。
  • 能说：剂量结论在两个策略上一致。π0.5（17 个任务）在 0 / 1 / 2 / 3 / 4 / 6 倍下为 53.8 / 59.9 / 62.9 / 68.8 / 72.1 / 74.4 %；在训练起点上调过剂量的表 72.5 %，比固定 2 倍高 9.6 个百分点（区间 +1.9 到 +20.4），比原生高 18.7；固化后的学生相当于原生策略多了约 0.8 个剂量单位（区间 0.35–1.80，残差约 1 个百分点），上限并不更高（PLA-DOSE-P05；π0 上对应为 71.8 %、+16.4、1.18 个单位）。
  • 能说：在第二个策略 π0.5 上（17 个任务，每臂 680 回合）：固化后的学生 59.9 %，比原生 52.8 % 高 7.1 个百分点（区间 +2.3 到 +12.1，登记的主假设确认）；不训练的 2 倍 / 3 倍平移为 64.3 / 70.3 %，学生没有超过 2 倍、明显低于 3 倍；学生保留了 2 倍平移收益的 62 %（π0.5 正式实验）。
  • 能说：平移是一种“剂量”：原生 π0 在 0 / 1 / 2 / 3 / 4 / 6 倍下为 29.6 / 42.1 / 55.4 / 62.5 / 68.6 / 61.1 %；固化后的学生相当于原生策略多了约 1.2 个单位（区间 0.83–1.63，残差 1.8 个百分点），上限并不更高；不训练、只按任务调剂量的表达到 71.8 %，比固定 2 倍高 16.4 个百分点（区间 +8.6 到 +24.3；PLA-DOSE）。
  • 能说：把 System 2（多试 + 官方判据）的挑选写成任务级噪声平移，π0 在 13 个任务的四次新测试里都显著提高（+15.4 / +23.1 / +22.5 / +18.7 pp），换到 10 个新的低成功率任务上也提高（+10.3 pp）。见 v2、v3、v4、v5、v6。
  • 能说（事后描述）：每个任务的提高可以复现：四个独立测试集之间逐任务收益的平均 Spearman 相关 0.60（随机打乱的 95 % 分位 0.21）；13 个任务里 10 个在四次测试中都提高，没有一个四次都下降。任务 51 的正负取决于起点（起点 20–29 两次下降，起点 10–19 两次上升）。
  • 能说：在 π0 自己的候选动作块里逐状态挑选，即使用仿真前瞻的理想裁判也只 +0.9 个百分点（区间 −5.2 到 +6.2），从未成功的任务 512 次续跑 0 次成功（PLA-Q）。
  • 不能说：同等预算下拟合的方向优于“留下最好的那张噪声票”。两个策略上结果一致：只花搜索预算、2 倍强度时，方向比最好的单张票低 3.2 个百分点（π0.5：62.9 对 66.2 %；π0：55.4 对 58.6 %）；总预算相等（双方都多花每任务 80 次试跑）时，调过剂量的方向在点估计上领先（π0.5：+3.4 / +5.3；π0：+8.9 / +5.7），但四个登记的比较都没有确认。事后把两个策略的 31 个任务合并，差为 +5.9（区间 +0.2 到 +12.4），只是提示，尚未登记确认（PLA-TKT-P05、v2、PLA-TKT-P0）。
  • 不能说：“学生 + 平移”优于查表。确认实验 PLA-R3 的三个登记假设都没有确认：学生 + 2 倍平移 64.6 %，与不训练、只把平移加到 3 倍的 65.7 % 几乎一样（PLA-R2 的 +11.1 是事后观察，不成立为固化的优势）。
  • 不能说：固化能迁移到没参与训练的任务——方向一致的留出任务也没有提升（−3.8 / −13.1；PLA-X）。成败型 System 2 的知识就是每任务一个固定偏置，按指令查表比改权重更好。
  • 能说：过门任务学 System 2 的成功轨迹、其它任务用 π0 自己的样本做锚，固化后的 π0 在 23 个任务整体上提高 +8.5 个百分点（两个种子都显著；PLA-G v4）；每任务更多引导数据没有更好。
  • 能说：同样的 rollout 数，只学 π0 自己的成功轨迹没有提升（+1.4），学 System 2 的门控学生比它高 +9.6 个百分点（两个种子都显著；PLA-C C-B）。
  • 还不能说：固化后的 π0 在 23 个任务整体上更好——五个学生都在 +2.8 到 +5.7 个百分点之间，未显示提升；只练过门任务会忘掉其它任务，全部任务一起练又会减半过门任务的收益（PLA-G v3）。
  • 能说：同样 192 次 rollout，直接在动作空间搜一个固定偏置也能拿到噪声平移约 80 % 的收益（51.4 % vs 56.8 %，差别未显示；PLA-C C-A）；不能说“必须在噪声空间搜索”。
  • 能说：只用训练起点上的配对结果就能预先判断 System 2 在哪些任务上对新起点有用（过门 +27.5 vs 未过门 +1.1 个百分点）；在这些任务上模仿后，π0 本身 +13.2 个百分点（两个种子），约为 System 2 收益的一半；但只练这些任务会让其它任务掉约 14 个百分点（PLA-G v2）。
  • 能说：在 System 2 稳定有效的任务上，模仿它的引导轨迹能把约 91 % 的收益搬进 π0 本身：新起点上 43.5 % → 73.0 %（+29.5 pp，McNemar p = 2e-11），测试时不带 System 2（PLA-I v1）；System 2 在 π0 单独失败的情况里救回 71 %。
  • 能说：13 个任务混在一起蒸馏时效果被抵消（PLA-O v1：+0.4 pp）；关键是只固化 System 2 稳定有效的任务。
  • 能说：平移的收益约 89 % 可以用每个任务一个固定的动作偏置拿到（PLA-B v1：偏置 61.3 % vs 平移 63.1 %，差 +1.7 pp 未显示）；平移在单个状态上造成的动作变化随状态而变，但起作用的主要是它的平均部分。
  • 能说：起作用的是拟合出的方向，不是“随便推一下”（v2：对随机正交平移 +18.3 pp）；也比直接复用最好的一张固定噪声更稳（v3：后者在 3 个任务上远低于原生）。
  • 能说：用权重固化同一份经验效果差得多：自我模仿没有提升（PLA v1 / v1c），蒸馏平移策略只保住约三分之一（PLA-D v1 / v2），训练时把噪声也配对仍只有 22.5 %（PLA-D v4），蒸馏权重再加平移也不超过只加平移（PLA-D v3）。
  • 能说：搜得越多收益越大：6 / 24 / 48 张固定噪声分别 +9.0 / +16.2 / +20.3 pp（v7）；48 对 24 还不显著。
  • 能说（描述性）：平移试 1 次大约抵得上原生试 2–3 次，多试几次时优势仍在（多试几次）。
  • 不能说：第二轮搜索有额外收益（v5）；门槛 G10 能挡住变差（v6 否定）；能“解锁”学生从来不成功的任务（PLA-Z v1：1,152 回合只成功 5 次）。
  • 局限：π0 上都是探索性实验（规则先写、只分析一次），正式登记的是 π0.5 上的 E20、E22-M；只在 LIBERO-90 仿真；RoboDojo 和第三个策略还没做。

做法

System 2 怎样变成 System 1 的一部分

① System 2 搜索

24 张固定噪声 × 8 个训练起点

每张固定噪声整局使用；LIBERO 官方成功判据给每张打分（8 个起点里成功几次）。每个任务 192 回合，不需要示范、不需要奖励模型。

② 固化

闭式拟合一个“好噪声方向”

只看噪声里会被执行的部分（前 5 步 × 7 个动作维度，35 个数），对 24 个分数做岭回归（λ = 10），取单位方向 d。

③ 部署

新采的噪声 + α·d

每次调用照常采标准正态噪声，再沿 d 推 α 倍（预先定为 2）。不改权重、不再搜索，每个任务只多存 35 个数。

对照的权重路线：把 System 2 挑出的回合拿来微调 π0 的动作专家（约 3 亿参数）——用学生自己的成功回合（自我模仿），或用平移后策略的回合（蒸馏）。部署时用普通噪声。

字段

先看字段含义

学生（System 1）
冻结的官方 π0 LIBERO 检查点。每次调用给出 50 步动作，执行前 5 步后重新规划；一局最多 400 步。
System 2
同一个起点上让学生用不同噪声多做几次，用官方成功判据挑出成功的。它只知道“这次成没成”。
噪声 z
流匹配策略生成动作时的起始随机数（50 × 32）。观测相同、z 不同，动作就不同；成败有很大一部分取决于 z。
原生
官方用法：每次调用重新采一个标准正态 z。
固定噪声（噪声票）
整局每次调用都用同一个 z。每个任务事先按编号生成 24 张，搜索时每张在 8 个训练起点上各跑一次。
拟合方向 d
24 张固定噪声的成功率对其前 5 步 × 7 维（35 个数）做岭回归得到的单位方向，只用搜索数据。
平移 α 倍
部署时原生噪声的那 35 个数加上 α·d，其余不变。α = 2 是事先定的剂量；3、4 倍是 v3 里加测的。
随机正交平移
大小相同、方向与 d 垂直的随机方向。用来排除“随便推一下也有用”。
最好的固定噪声
搜索中得分最高的那一张（并列取编号小的），部署时整局固定使用。
自我模仿微调
用 System 2 挑出的学生自己的成功回合，只微调动作专家；对照组用同样数量、不看成败随机抽的回合。
蒸馏
用“平移 2 倍”的策略当老师在训练起点上采回合，再微调动作专家；部署时不加平移。
起点
LIBERO 官方给每个任务的 50 个初始状态之一（编号 0–49）。搜索 / 训练用 0–9，测试用从未用来拟合或挑选的编号。
种子
同一起点上的原生噪声序列编号。同一起点、同一种子，各组用同一串原生噪声，所以可以逐回合配对。
配对 a / b
同一起点、同一种子下，只有前一组成功的回合数 / 只有后一组成功的回合数。
95 % 区间
先算每个任务的成功率差，再对任务做 4,000 次重抽样。以任务为单位，比逐回合检验保守。
判定
区间下限 > 0 记 GAIN；上限 < 0 记 HARM；否则记“未显示”。只对事先写定的比较下判定。
规则写定
计划文件里标注的时间：组别、测试起点、主比较和判定规则在测试数据出现之前写下。
门槛 G10
24 张固定噪声里至少 10 张成功过才部署平移。看过 v2 后提出，在 v6 的新任务上检验：不成立（会丢掉一半以上的收益）。

为什么

权重路线为什么没有提升，任务 51 又是怎么回事

权重路线

  • 不是代码问题：学习率为 0 的“空训练”与原模型逐回合一致（360 / 360，成败和回合长度都相同）。
  • 自我模仿：中等训练量暂时变差，训练 4,000 步回到原水平；即使在 System 2 解出 49 / 60 的训练起点上，学生也只有约 29 %。
  • 蒸馏平移策略：保住约三分之一的提升；只用成功回合和用全部回合一样，说明学到的是平移后的行为本身。
  • PLA-D v3：在蒸馏权重上再加平移，不超过只加平移；在 D_ALL 权重上平移几乎失效。两种固化抓的是同一件事。
  • PLA-D v2：换成老师完整动作块当标签（更差，−5.2 pp），或让学生自己走、老师逐点标注（+4.2 pp，不显著），都没有越过三分之一。训练损失几乎不降：老师与学生是同一网络，动作样本分布很接近，模仿动作学不到“噪声往哪推”。
  • PLA-D v4（耦合蒸馏）：训练时学生的噪声固定为采集时的原生 z，目标是老师在同一 z 上加平移后的动作。训练损失降到约四分之一（0.0062 → 0.0028），但 K_ON 51.2 %、K_OFF 53.1 %，搬进比例 22.5 %。所以“标签和噪声对不上”不是原因；学生拟合得准，却没变成测试起点上的行为。下一步用诊断 F 区分是没拟合上执行块，还是跨状态没泛化。
  • 推断：成败主要取决于噪声在关键维度上有没有一致偏向；模仿动作很难抓住它，直接学噪声方向可以。RoboDojo 模仿线修复训练框架的 EMA 漂移问题后，自我模仿同样没有提升。
