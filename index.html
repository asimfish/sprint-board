Where we stand

Training data is collected; the risk is whether the value model can rank candidates inside a state. Collection finished 236 of 240 training states on cluster A (16 accelerators). A trial fit on 200 states learned how hard each state is (pooled AUC 0.79) but ranked candidates within a held-out state at chance (0.44).

We changed course before any evaluation ran. The learned 3,200-d value memorised training states (held-out within-state AUC 0.33–0.44). Two training-data diagnostics then showed real signal: which noise candidate you pick changes success beyond continuation noise (dispersion ratio 1.21, permutation p = 1e-4), and a low-capacity value on the 7 action-relevant noise dimensions ranks candidates in unseen states at 0.56, up from 0.54 as data grew. The same features built from the other 25 noise dimensions stay near chance. They still pass through π0.5's action network, so they are a comparison, not a strict negative control. v5.2 adopts this value and concentrates evaluation on non-saturated tasks, both registered before any evaluation.

The paper compiles at 8 main-text pages with Table 1, figures V26 are in, and results are still TBD. The expected-results preview below shows what the paper will say if the target is met. Those numbers are not measurements.

What the trial value model learned

Pooled AUC equals the AUC of predicting each state's mean, so the model learned state difficulty, not which candidate is better. Within-state ranking is what ASBS needs.

Signal diagnostics (training data only, 08:00 snapshot, 268 states, 50 mixed)

Held-out within-state ranking AUC by candidate representation. Chance is 0.5; the permutation 95th percentile is about 0.57–0.58.

Overdispersion across 50 informative states: candidate-mean variance is 1.19× the binomial expectation (dispersion ratio 1.21, permutation p = 1e-4). φ(z) trend: 0.544 at 236 states → 0.560 at 268 states.
